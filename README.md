# Convite de Casamento — Fábio & Dalyne

Convite digital (uma única página HTML) para o casamento de **Fábio e Dalyne**,
em **19 de dezembro de 2026**, na **Igreja do Céu — Viçosa do Ceará**.

## Como publicar

O arquivo `index.html` funciona sozinho. Para colocar no ar pelo GitHub Pages:

1. No repositório, vá em **Settings → Pages**
2. Em *Source*, escolha a branch e a pasta `/ (root)`
3. Salve — o convite ficará disponível no endereço indicado pelo GitHub
